BOLT LOG — INSTALLABLE WEB APP
Deploy index.html, manifest.webmanifest, sw.js and both PNG icons at the same HTTPS path (e.g. GitHub Pages). No build step is needed. The deployable app starts empty; restore the separate bolt-log-initial-data.json in Data & backup to import your existing trips. Do not upload that backup to a public repository. Open the site in Android Chrome, then use Install app or Add to Home screen in the menu. Entries are local to the browser/device; export JSON for restore and CSV for analysis. Offline use requires one successful online load. The supplied historical dates are unknown; the third commute assumes the previous arrival is the parked baseline. Change the override or mark unknown in Edit if there was an interruption. All charge figures are net battery percentage points, not energy in kWh.
